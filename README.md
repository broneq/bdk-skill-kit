# bdk-skill-kit - moved

This repository is archived. `bdk-skill-kit` now lives in the BDK repository, with its full history:

**https://github.com/broneq/bdk/tree/main/plugins/bdk-skill-kit**

- Install it from the BDK marketplace, as before: `/plugin marketplace add broneq/bdk`, then `/plugin install bdk-skill-kit@bdk`.
- Issues and pull requests go to [broneq/bdk](https://github.com/broneq/bdk).
- Releases continue there as tags `bdk-skill-kit--v<version>`. The tags of this repository stay readable, so existing pins keep working.
